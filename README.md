DomiBatalla by Joanfi — Tres en Raya

Nombre completo: Joanfi Espinal Lopez

Descripción del juego

DomiBatalla es un juego de Tres en Raya desarrollado con React. Está diseñado para dos jugadores que se turnan para colocar sus fichas X y O en un tablero de 3 × 3. El objetivo es conseguir tres fichas en línea, ya sea horizontal, vertical o diagonalmente. El juego también detecta los empates y permite iniciar nuevas partidas.

Su diseño tiene un estilo futurista, con colores llamativos y una temática inspirada en la República Dominicana.

¿Qué aprendí?

Con este proyecto aprendí a trabajar con React para crear una página interactiva y a utilizar estados para controlar los turnos de los jugadores y actualizar el tablero. También aprendí a implementar las reglas para detectar victorias y empates, utilizar CSS para diseñar la interfaz y organizar los archivos de un proyecto web. Además, comprendí cómo utilizar Vite para ejecutar y compilar la aplicación.

¿Qué parte fue más difícil?

La parte más difícil fue implementar la lógica del juego para que los turnos cambiaran correctamente y se detectaran las combinaciones ganadoras sin permitir movimientos después de finalizar la partida. También tuve que prestar atención a la conexión entre React y los archivos CSS para que el diseño se mostrara correctamente.

A pesar de las dificultades, el proyecto me ayudó a comprender mejor cómo se relacionan la lógica y el diseño en una aplicación web.
